# Smart Cough Analyzer

AI-powered respiratory disease detection using cough audio and Deep Learning.

## Features
- Cough audio upload
- Mel-Spectrogram generation
- CNN / EfficientNetB0 prediction
- TensorFlow Lite support
- Streamlit web app

## Technologies
- Python
- TensorFlow
- Librosa
- Streamlit
- NumPy
- Matplotlib
